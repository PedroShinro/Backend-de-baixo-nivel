# Calculadora em C

Projeto de uma calculadora simples desenvolvida em **C**, utilizando a **Windows API (Win32)** para criação da interface gráfica.

## Funcionalidades

A calculadora permite realizar as seguintes operações:

- Soma
- Subtração
- Multiplicação
- Divisão
- Limpeza dos campos
- Encerramento da aplicação

O programa também possui validações para:

- Campos vazios;
- Tentativa de divisão por zero.

## Interface

A aplicação possui dois campos para entrada de números e botões para selecionar a operação desejada.

O resultado da operação é exibido em uma caixa de mensagem.

## Tecnologias utilizadas

- Linguagem C
- Windows API (Win32)
- Dev-C++

## Como executar

Para utilizar a calculadora, execute o arquivo:

`calculadora.exe`

O programa foi desenvolvido para o sistema operacional **Windows**.

## Código-fonte

O código-fonte da aplicação está disponível no arquivo:

`calculadora.c`
